# Art direction

BriefProof uses warm ivory surfaces, dark editorial typography, restrained violet accents, clear information hierarchy and portfolio-led discovery.

The bundled WebP atlases contain original AI-generated artwork and fictional portraits. They are illustrative sample content, not authentic creator identities or commissioned portfolio evidence. Profile metadata is seeded from `src/data/creators.ts`.

The creative-studies atlas contains four directions: a premium serum still life, a cobalt sculptural object, a desert sphere composition and a sage sneaker concept. The portrait atlas contains eight distinct fictional adults. CSS background positions select the corresponding atlas tile; no third-party image host is required.

For a real marketplace, replace these illustrative assets and sample profile records with authorized creator material and verified declarations.
